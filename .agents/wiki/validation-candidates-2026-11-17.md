# Validation run 2026-11-17: deferred candidates

Findings from the 2026-11-17 chief-of-staff validation run (the grilling cluster, see [grilling-upstream-cluster.md](grilling-upstream-cluster.md)) that were recorded but not fixed in this run, each with the reason it is deferred and the fix that would close it. Dated claims; nothing here is a description of the present.

## 2026-11-17

- **Sequential merger worktrees never release the integration branch** (from the retro on the merger 2 session; category: Automated checks). Evidence: merger 2's first checkout of `fix/grilling-upstream-cluster` failed (exit 128) because merger 1's worktree still held the branch, forcing a detach of a worktree the task had not mentioned. The root fix, per the retro, is in `skills/engineering/implement-spec/SKILL.md`: step 5 should release the previous merger's worktree (remove it, or detach its HEAD) before the next merger is dispatched, and step 9 ("Clean up all implementer subagent worktrees") should cover merger worktrees, which it does not as written. Deferred because the session's branch scope allowed no implement-spec commit on `t3/cos-validation` and no non-grilling commit on the integration branch; the run mitigated it by putting the detach procedure into each later merger's task text.
- **No em-dash guardrail over general prose** (from the same retro; category: Automated checks). The only wired guardrail on 2026-11-17 was `.githooks/commit-msg`, which exempts merge commits; the wiki lint covers the wiki folder only; there is no CI. The retro's proposed fix: a `.githooks/pre-merge-commit` hook (git skips pre-commit on merge commits and runs pre-merge-commit instead), rejecting the merge when a staged prose file carries U+2014, plus the known-working check command in dispatch texts. On this machine the working forms are the literal character (`grep -n $'\u2014'`) and hex bytes (`grep -P '\xe2\x80\x94'`); the PCRE code-point form `grep -P '\x{2014}'` fails with a code-point limit error, which is exactly the form the merger 2 session tried first. Deferred for the same branch-scope reason.
- **to-spec gives no local-tracker layout for the spec itself.** `to-issue` defines the local file layout for issues (`.scratch/<feature-slug>/issues/<NN>-<slug>.md`), but `to-spec` only says to publish the spec to the tracker. The run inferred `.scratch/grilling-fixes/spec.md`. A one-line addition to `to-spec` would close it. Deferred: to-spec is not in this session's commit scope.
- **Implementer access to a local tracker.** The local tracker files live untracked in the orchestrator's worktree, so an implementer subagent in its own worktree cannot see them by repo-relative path; the dispatch must pass absolute paths. The run worked by passing absolute paths in every task. `implement-spec` and `to-issue` are silent on the local-tracker-plus-worktrees combination. Deferred: out of commit scope; the mitigation is one line of dispatch text.
- **Review mechanical recounts need a grep.** The review's Standards axis reported two "sub-agent" spellings in the grilling docs page; the page actually held three (a possessive occurrence the count missed). The fixer subagent found the third while applying the fix. Mechanical claims in a review (occurrence counts, "no X in Y") should be verified by the same command the fixer will run. Deferred: a `code-review` process note, out of commit scope.
- **chief-of-staff has no docs page.** As of 2026-11-17 it is the only promoted skill without a docs page: the 2026-11-17 promotion into `engineering` (commit 7a001d9) moved it without creating `docs/engineering/chief-of-staff.md`, and the two chief-of-staff fixes of the same day (7b55a24, 0c19057) add to the owed re-sync. The session's commit scope (wiki pages plus the chief-of-staff skill file only) barred a docs-page commit. Create the page when the branch merges.
- **sub-agent vs Subagent spelling drift is repo-wide.** `docs/ai-coding-terms.md` lists the term as Subagent, but the hyphenated spelling coexists across at least six files on 2026-11-17, including skill files whose voice the grilling branch did not touch. The grilling docs page was aligned on 2026-11-17 (commit 9421568 on the integration branch). The wider drift needs its own pass.
- **Wiki lint wiring stayed manual.** The chief-of-staff skill says to wire the wiki lint into a pre-commit hook or CI where the environment has one; the repo has `.githooks` with `core.hooksPath` set, but this session's commit scope barred adding a hook file, so the lint was run manually before every wiki commit. The retro sharpens the target: for an em-dash check that must also cover merge commits, the hook to wire is `pre-merge-commit`, not `pre-commit`.
